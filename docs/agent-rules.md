# Agent rules

- Use the API, not a browser.
- Never print, log, commit or paste secrets or tokens.
- Reads are free. Writes (timeslips, invoices) need the plan shown and a clear yes, unless the user already gave exact details and told you to proceed.
- Draft only for invoices; never send.
- After every write, read it back and report what FreeAgent holds.
- Do not modify or delete entries you did not create in this task; report conflicts instead.
- Put business-specific values in the consuming repo, never here.
