# Agent rules

Every skill follows these.

- Use the API, not a browser.
- Do not print, log, commit or paste secrets or tokens.
- Read freely. Before any write, show the plan and wait for a clear yes. You can skip this when the user gave exact details and told you to go ahead.
- Check for duplicates before creating anything.
- After each write, read the entry back and report what FreeAgent holds, not what you sent.
- Leave entries you did not create in this task alone. Report conflicts instead.
- If a business detail (ID, rate, category, reference format) is missing, ask.
